# ejemplo/

Un archivo de muestra para ver Anarchivo funcionando antes de tener el tuyo. Todo lo que hay aquí es inventado como ejemplo: dos proyectos, un artefacto, un ensayo, una constelación, una bitácora y un vocabulario de seis conceptos (`concepts.ts`).

Es lo que el dashboard abre si no le dices otra cosa (`"playbook": "ejemplo"` por defecto). Para pasar a tu propio archivo, ver [docs/montar-tu-anarchivo.md](../docs/montar-tu-anarchivo.md) §5.

Sirve también de plantilla: copia la forma de un `concepto.md`, de un `imagenes.yaml` o de `concepts.ts`.
